## Try it in one command

```sh
npx tablewalk --demo
```

This builds a sample database in your temp directory and opens it. Nothing of yours is touched. To open your own:

```sh
npx tablewalk ./data/app.db
npx tablewalk postgres://user@localhost:5432/appdb
```

Then go to `http://localhost:4111`, or add `--open` to have it open a browser for you. The server listens on loopback only. [Getting started](/docs/getting-started/) goes from there.
