## Try it in one command

```sh
npx tablewalk --demo
```

{/* Remove once the browser-only release is published. */}
Until the browser-only release is published, `npx tablewalk@next` is the current build.

This builds a sample database in your temp directory and opens it. Nothing of yours is touched. To open your own:

```sh
npx tablewalk ./data/app.db
npx tablewalk postgres://user@localhost:5432/appdb
npx tablewalk ./exports/
```

Point it at a SQLite file, a PostgreSQL URL, or a `.sql` / `.csv` / `.tsv` / `.ndjson` file or folder, then open `http://localhost:4111` (or pass `--open`). The server listens on loopback only, switches between `local`, `staging` and `prod` in place, and ships nineteen [built-in looks](/docs/browsing/#looks-and-preferences) (`Folio` by default, plus `Instrument`, `Braun`, `Broadsheet`, `Obsidian`, `Blueprint`, `Console`, `Gallery`, `Lumen` and more). [Getting started](/docs/getting-started/) goes from there.
