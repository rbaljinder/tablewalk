---
title: Keyboard
description: Every key tablewalk listens for, from the query bar to the result grid. The same list is in the app under ?.
---

tablewalk can be driven from the keyboard. Press `?` in the app for this list beside the query language.

Single keys work when the caret is not in a text field, and never through a dialog. On Windows and Linux, `Ctrl` stands in for `⌘`.

## Anywhere

| Key | Does |
| --- | --- |
| `h` | Home: the schema, your work, the diagram |
| `/` | The query bar |
| `⌘/` | The query bar as a panel, with room to write in |
| `t` | The table filter in the sidebar |
| `⌘K` | The command palette: tables, pages, actions, recent queries |
| `⌘B` | Show or hide the table list |
| `⌘⇧↵` | The SQL editor |
| `Backspace` or `⌘[` | Back one step along the trail |
| `⌘Z` | Undo the last write, in [write mode](/docs/writing/) |
| `?` | The query language and these keys |
| `Esc` | Leave the field, or close what is open |

## In the query bar

| Key | Does |
| --- | --- |
| `Ctrl+Space` | Open the completion list |
| `Tab` | Take the highlighted completion, or the first one |
| `↑` `↓` | Move through the list; with `Shift`, select a range (for `show`) |
| `Enter` | Take a highlighted completion, or run the query |
| `Esc` | Close the list, then leave the bar |

## In a result grid

`Tab` into the grid, then the arrow keys move a cell cursor.

| Key | Does |
| --- | --- |
| `↑` `↓` `←` `→` | Move one cell; hold `⌘` to jump to the end of the row or column |
| `Enter` | Open the record for that row |
| `Space` | Glance at that row's record; `j` and `k` step, `Esc` closes it |
| `⌘C` | Copy the cell under the cursor |
| `Home` / `End` | First and last column |
| `Esc` | Back to the query bar |

## On a record opened from a list

| Key | Does |
| --- | --- |
| `j` | The next record in the list |
| `k` | The previous record |
| `←` `→` | The same, with the arrows beside the record's name |

## In the SQL editor

| Key | Does |
| --- | --- |
| `⌘↵` | Run the statement |
| `Esc` | Close the editor |
